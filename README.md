# DermaInsight AI

A modular local research application for biomedical images, EHR preprocessing, clinical text and healthcare analytics. Research only; never a confirmed diagnosis or treatment recommendation.

Development in progress. No datasets or lesion model supplied. See [project plan](docs/PROJECT_PLAN.md), [required inputs](docs/USER_ACTION_REQUIRED.md) and [verification](docs/TEST_RESULTS.md). Missing-data states are intentional; predictions and statistics are never fabricated.
