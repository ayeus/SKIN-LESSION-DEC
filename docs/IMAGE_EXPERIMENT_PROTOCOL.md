# Content integrity and frozen-choice CNN experiment protocol

## Acquisition and content
Official ISIC2018 archives remain outside Git. A resumed download preserves its prefix only with matching recorded source ETag/length. Bounded HTTP range requests require exact Content-Range, response ETag and byte count; cached chunks require matching source/range/SHA-256. Assembled archives pass size and ZIP CRC checks before extraction. ETag/local SHA is not described as a publisher cryptographic checksum. Interrupted transfers and failed attempts are never treated as complete. Extracted files are written atomically.

Full manifest content audit decodes every input, validates permitted format/dimensions, hashes both encoded bytes and EXIF-oriented RGB pixels and rejects cross-group exact duplicates, including differently encoded copies. Invalid/missing images are reported without substitution. This does not detect all near-duplicates or establish patient independence. Legitimate patient groups may include lesions with different labels; grouped splitting retains them together.

## Executed validation-only comparison
Run `.venv/bin/python -m scripts.audit_lesion_images` after complete extraction, then `.venv/bin/python -m scripts.compare_lesion_models --epochs 3 --batch-size 16`. The runner uses the entire configured cohort; no hidden subsampling or synthetic fallback. Small CNN trains all layers. ResNet18/EfficientNet-B0 comparison candidates use genuine torchvision ImageNet backbones with frozen weights/BatchNorm and train their heads only. These are explicit short CPU-budget configurations, not fully fine-tuned architecture optima or clinical models. ImageNet weights alone enable no lesion prediction.

Each candidate uses the same documented group split and seed, class-weighted loss and validation checkpoint selection. `defer_test=True` evaluates only validation after fitting: no held-out test pixels pass through a candidate for evaluation, and no test embeddings are generated. Checkpoint/comparison criterion is minimum class-weighted validation loss. A frozen choice is written to `data/experiments/EXPERIMENT_UUID/frozen-choice.json` **before** test inference. Only that chosen artifact is then evaluated once on the held-out test. Metadata/image fingerprints must match training. Validation-only candidates cannot be selected, advertised as inference-ready, predicted with or explained as final inference artifacts. Legacy single-run training remains available, but repeated use of its test reports for architecture selection is not independent evidence.

The comparison completed locally in experiment `6b7ba82c-233b-4fdf-8008-221d914f0e0a`. Small CNN, ResNet18 and EfficientNet-B0 each trained for three epochs. The validation-only winner was EfficientNet-B0 (best class-weighted validation loss 1.02842); the choice file was written before the held-out test was exposed. Its independent held-out test contained 2,014 lesion-grouped images: accuracy 0.62115, balanced accuracy 0.51307, macro F1 0.41722, weighted F1 0.65978. Per-class metrics and the confusion matrix are in its manifest at `data/models/d8cadd12-e7e4-42c4-8e31-0410d095bc91/manifest.json`. These are measured results for a short frozen-backbone research baseline, not clinical effectiveness; class performance is uneven and scores are uncalibrated. The selected artifact was subsequently exercised with actual HTTP and browser inference/Grad-CAM.

The trained segmentation model is documented with its separate cohort and protocol in DATA_ACQUISITION.md and LOCAL_DEMO.md. Clinical, patient-disjoint/external and skin-tone validation remain separate and have not been performed.
