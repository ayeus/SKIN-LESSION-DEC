# Interface design

Subject: a research bench for biomedical imaging and healthcare datasets. Primary job: make each result traceable to an actual input and execution.

Tokens: deep petroleum #173b46 (navigation), teal #087f83 (actions), ice #f4f8fa (workspace), white #ffffff (working surfaces), slate #617681 (supporting text), amber #ce8b32 (focus).
Typography: Avenir Next where installed, Avenir/Segoe UI/system fallback. Compact navigation with larger, calm research titles. Local fonts avoid external network/font requirements.
Layout: left-aligned persistent module navigation; thin connection/status header; working canvas with comparison panels, source-schema inspection and execution history. Mobile navigation collapses behind a labeled menu button.

    Navigation | Connection and workspace location
               | Module title and scope
               | Input / explicit algorithm parameters
               | Actual outputs, plots and export

Review: identical decorative metric cards are limited to actual overview counters; empty states explain the precise input needed. The signature research microscope illustrates method rather than an invented lesion or arbitrary heatmap. No decorative chart data, patient records or predictions. Clinical limitations sit beside the action/results they qualify.
